# Ketuduke V4.5 baseline flow

The reproducible fixture used by the flow tests has a horizontal center crystal at zero-based `(1, 1)`, clockwise wind, T/H bubble buffs, and spread resolution.

1. Select `MT` and start. The trainer enters phase 0 with crystals and buffs visible; mahjong is hidden.
2. Select the V4.5-generated queue cell. Confirming before reveal records a checked answer but remains in phase 0.
3. The 80 ms timer loop observes the five-second boundary at 5.04 seconds, reveals mahjong, and advances a checked answer to phase 1.
4. Select the `solveParty()` pre-wind cell for MT and confirm. The test disables visual playback but executes the same final two-pass displacement and crystal target calculation.
5. The trainer enters phase 2, locks input, validates final geometry and grouping, and increments wins and streak.

The timer baseline also verifies that an unanswered round reveals mahjong without leaving phase 0, then locks and opens the death dialog at ten seconds.
