# FFXIV Criterion Dungeon Mechanics Trainer

FF14 異聞迷宮機制練習網站。目前以阿羅阿羅島一王「凱圖嘟凱」排隊法練習器為主要開發內容。

## 目前開發進度

- 已建立 Vue 3、Vite、TypeScript 與 Vue Router 專案架構。
- 首頁已列出希拉狄哈水道、六根山與阿羅阿羅島；前兩者目前標示為準備中。
- 已建立凱圖嘟凱練習器路由與深色介面，保留桌面版左側棋盤、右側控制區的配置。
- 已從 Legacy V4.5 抽離題目生成、排隊、安全區、水晶、風吹與四人站位等純 TypeScript 邏輯。
- 已完成角色選擇、開始練習、排隊確認、麻將揭示、吹風前站位、重試、新題目、提示與 YOU DIED 流程。
- 實戰模式目前使用兩個獨立的 5 秒判定窗口：排隊 5 秒、吹風前站位 5 秒。提前確認成功會立即進入下一階段，並重新取得完整 5 秒。
- 已補上①／②麻跑法提示、角色位置保留，以及固定正方形的 4×4 棋盤。
- 已建立 Golden Tests、Legacy 相容性測試、流程測試與 Vue Composable 互動測試。

## 尚未完成

- 兩段吹風動畫，以及角色與水晶的畫面位移。
- 最終安全區、傷害範圍、分攤／分散與勝敗結算畫面。
- 結算回放、勝場與連勝統計的完整流程。
- 希拉狄哈水道、六根山，以及阿羅阿羅島其他王與機制練習器。

## 下一步預計確認與修正

換機後請先針對「排隊與吹風前站位各自獨立 5 秒判定」進行瀏覽器手動驗收。此功能目前已有自動化測試基準，下一步應優先確認 4.9／5.0 秒邊界、提前確認後的完整第二階段時間，以及重試、換題與模式切換時是否仍能正確清除舊計時器；若實際操作與預期不同，再針對計時狀態修正。確認穩定後才開始移植吹風動畫。

## 本機開發

```sh
npm install
npm run dev
```

驗證指令：

```sh
npm test
npm run typecheck
npm run build
```

## Legacy 基準

`legacy/ketuduke-v4.5.html` 是原始行為基準，遷移期間不得直接修改。疑似機制錯誤應先記錄為已知問題，不應在重構時自行修正。
